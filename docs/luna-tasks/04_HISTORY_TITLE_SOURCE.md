# Luna Task 04：履歴タイトル生成元の分離

## 目的

履歴・右側履歴・ギャラリー・画像詳細のタイトルを、廃止済み日本語生成用の `description` から分離してください。新規履歴は独立した `title` を確定保存し、古い履歴は従来表示を維持します。

## 現状

経路は次のとおりです。

```text
promptDescription
→ POST /api/jobs の description
→ src/server.js の generate()
→ history.addGeneration({ description })
→ normalizeGeneration().description
→ 右履歴・ギャラリー・詳細の見出し
```

`description` はPrompt生成、派生生成、履歴復元などでも使われています。削除や一括改名はしないでください。

## 推奨データ契約

- 新規の履歴フィールド `title: string` を追加する後方互換方式にしてください。
- 古い履歴の表示名は `generation.title || generation.description || "無題"` としてください。
- `description` は旧履歴互換と日本語生成入力のため残し、新規タイトル決定には参照しないでください。
- schemaVersionを上げる場合も、全履歴を書き換える強制移行は不要です。正規化時のfallbackを優先してください。

## 主な変更対象

- `public/index.html`
- `public/app.js`
- `src/server.js`
- `src/history.js`
- タイトル組み立ての純粋関数用ファイル1つ（推奨）
- `test/history.test.js`
- `test/server-integration.test.js`
- 純粋関数用テスト1つ（追加する場合）

8ファイルを超える場合は実装前に報告してください。

## UI

1. 生成画面の生成設定アコーディオン内、詳細設定より上へ任意の「タイトル」入力を追加してください。
2. 空欄を許可し、最大長をサーバー側と一致させてください。目安は120〜200文字です。
3. 設定画面へ「タイトル生成方式」を追加してください。
4. 選択肢は少なくとも「日時」「キャラクター欄」「Model名」「キャラクター＋日時」「キャラクター＋衣装」「カスタムテンプレート」です。
5. 初期値は「キャラクター＋日時」としてください。
6. カスタムテンプレート時だけ入力欄を表示し、使用可能変数 `{character}` `{outfit}` `{model}` `{seed}` `{date}` `{time}` を補助表示してください。
7. 非機密の表示設定なので、既存方針に合わせてlocalStorageへ安全に保存して構いません。壊れた値は初期値へ戻してください。

## タイトル確定

1. 手動タイトルがあればtrim後の値を最優先します。
2. 空なら選択された方式で自動生成します。
3. Random Seedは生成完了後の実Seedを使えるよう、最終確定は保存済み画像が揃ったサーバー側で行うことを推奨します。
4. 複数枚生成は1つのgenerationタイトルを共有します。`{seed}` は先頭画像のSeedを使う、と仕様を固定してください。
5. 「キャラクター」はstructured promptのCharacter欄、「衣装」はAppearance / Outfit欄から取得してください。全文ではなく、表示用に先頭の有意なタグを安全に切り出してください。
6. キャラクターが空の場合は日時へfallbackしてください。
7. 未知のテンプレート変数は空文字にするか、その変数だけ無視し、例外にしないでください。
8. カンマや空白が連続した場合だけ表示用に整え、元Promptは変更しないでください。
9. 履歴作成時に確定した `title` は、後の設定変更で再計算しないでください。

## 表示側

タイトル取得を各画面で個別に書かず、`generationTitle(generation)` のような小さな共通関数へ寄せてください。少なくとも以下を更新します。

- 生成画面右の最近履歴
- ギャラリーカード
- 画像詳細モーダル
- メイン画像altと拡大モーダルのタイトル
- 派生生成・再生成後の表示

Prompt復元に使う `description` はタイトルへ置換しないでください。

## 禁止

- `description` の削除
- 古い履歴の一括タイトル再生成
- Prompt全文・Negative Prompt・AI翻訳結果のタイトル利用
- 履歴表示のたびの再計算
- 配列インデックスを識別に使う

## テスト

- 手動タイトル優先
- 空欄で各自動方式
- キャラクターなしの日時fallback
- Random Seedで保存後の実Seed
- 不明テンプレート変数
- 古い `title` なし履歴が `description` で表示される
- `description` も空の履歴は「無題」
- 設定変更後も保存済みtitleが変わらない
- Prompt生成と履歴復元が従来どおり

## 完了条件

- 新規履歴のタイトルが日本語生成用文章に依存しない
- 手動タイトルと自動タイトルを選べる
- 古い履歴表示を維持する
- Prompt生成、再生成、派生生成、履歴復元を壊さない
- `npm run check` と `npm test` が成功する
