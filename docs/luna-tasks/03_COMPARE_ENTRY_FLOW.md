# Luna Task 03：画像比較の導線改善

## 目的

既存の2〜4枚比較機能を作り直さず、「追加」「現在件数」「比較開始」「解除」の導線を明確にしてください。比較実験機能とは視覚・文言上で区別してください。

## 現状

- `public/app.js` の `compareSelection` が画像IDをキーに最大4枚を保持します。
- `toggleCompareSelection()`、`updateCompareButton()`、`compareCurrentSelection()` が既にあります。
- `public/compare-view.js` は横並び、原寸切替、同期ズーム・パン、設定差分、LoRA差分、Prompt差分を実装済みです。
- ギャラリー上部のボタン以外では件数が見えず、ヘッダーの比較タブにも件数がありません。
- `viewCompare` は主に「比較実験」の画面で、通常画像比較の0枚・1枚案内がありません。

## 主な変更対象

- `public/index.html`
- `public/app.js`
- `public/style.css`
- `public/compare-view.js`（削除操作を比較モーダル内へ追加する場合だけ）
- `test/ui-shell.test.js`
- 必要なら既存 `test/compare-view.test.js`

## 必須実装

1. ヘッダーの比較ナビへ、候補が1枚以上の時だけ件数バッジを表示してください。0件時は非表示または0を表示しない静かな状態にしてください。
2. 中央ツールバーのラベルを状態に応じて「比較に追加」「比較から外す」にしてください。狭幅で表示を短縮する場合も `aria-label` と `title` は完全な文言にしてください。
3. ギャラリーカードの比較ボタンも同じ状態文言へ同期してください。クリックでカードの拡大や選択を発火させないでください。
4. 追加・解除直後に既存Toastで状態を通知してください。Toastのアクションとして「比較画面を開く」を出しても構いません。
5. 比較候補が1枚以上ある時、ヘッダー直下または各トップレベル画面を隠さない位置へコンパクトな比較トレイを表示してください。
6. トレイはサムネイル最大4枚、件数、「比較を開始」、「すべて解除」を持ちます。固定バーで中央画像やモバイルナビを覆わないでください。
7. 0枚では「比較する画像がありません」とギャラリーへの導線、1枚では「あと1枚追加すると比較できます」を `viewCompare` 内に表示してください。
8. 2枚以上では既存 `compareCurrentSelection()` / `openCompareView()` を呼んでください。新しい比較表示を重複実装しないでください。
9. 比較候補を個別に外せる操作をトレイに用意してください。可能なら既存比較モーダルにも削除操作を追加しますが、大規模化する場合はトレイからの削除を優先してください。
10. `compareSelection` は既にトップレベル画面遷移で保持されます。このセッション保持を維持し、今回はlocalStorage永続化を追加しなくて構いません。

## 比較実験との区別

- ヘッダーのトップレベル名は「比較」のままで構いません。
- 通常の選択画像比較を「画像比較」、パラメータを変えて生成する既存機能を「比較実験」と明示してください。
- 既存の比較実験API、実験一覧、投票、生成キューには触れないでください。

## 禁止

- `compareSelection` と別の比較候補Stateを作る
- 新しい比較モーダルを作る
- スライダー比較の追加
- 比較実験のAPI・データ変更
- 履歴順序の変更
- 4枚上限の変更

## テスト

- 0、1、2、4枚で件数・ボタン状態・案内が正しい
- 5枚目が既存上限で拒否される
- 追加済み画像は「比較から外す」になる
- すべて解除でMap、バッジ、トレイ、各ボタンが同期する
- ギャラリーカードの比較クリックで画像拡大が発火しない
- 2枚以上で既存 `openCompareView()` が使われる

## 完了条件

- どこから比較へ追加するか分かる
- 現在の件数と追加済み状態が分かる
- 0枚・1枚でも次の操作が分かる
- 2〜4枚で既存横並び比較を開始できる
- 個別解除と全解除ができる
- `npm run check` と `npm test` が成功する
